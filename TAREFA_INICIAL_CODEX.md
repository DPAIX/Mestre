# Primeira tarefa recomendada para o Codex

Leia o `AGENTS.md`, o `README_CODEX.md` e os módulos do projeto MeuControlePC v2.2.1. Execute todos os testes locais. Faça uma auditoria com foco em: autorização do bot Telegram, isolamento do painel HTTP local, segurança de comandos Windows/RoboTask, gerenciamento de erros/quotas Multi-IA, confiabilidade dos JSON, inicialização e reinício do assistente, logs com redação de segredos e idempotência das melhorias seguras.

Reproduza e corrija bugs confirmados, mantendo compatibilidade com a migração dos dados legados. Acrescente testes para cada correção. Não invente resultados, não use credenciais, não desligue nem reinicie o Windows, não execute tarefas RoboTask. Produza um resumo com arquivos modificados, resultado de testes, riscos pendentes e procedimentos de validação manual no Windows. Não aplique as correções automaticamente no computador real.
